The platform

From raw identity telemetry
to an auditable decision.

One security boundary for detection, risk scoring, policy decisions, alerts, and evidence. Built for tenant-aware enterprise deployments.

◈

Risk intelligence

Correlates failed authentication, device novelty, travel anomalies, privilege changes, and session signals into an explainable risk score.

◇

Policy decisions

Returns an explicit allow, step-up, or deny decision that can be consumed by security and identity workflows.

▣

Evidence ledger

Preserves security assessments and audit evidence so investigations have a durable, tenant-scoped trail.

Architecture

Designed around
security boundaries.

FastAPI provides the policy boundary, PostgreSQL provides durable state, Redis provides distributed controls, and workload identity can be anchored to SPIFFE/SPIRE.

Detection pipeline

Authentication event → identity context → detection rules → risk engine → policy decision → alert → audit ledger.

Auth Event→Context→Detection→Risk→Evidence

Production controls

Tenant-aware RBAC, API-key authentication, PostgreSQL persistence, Redis rate limiting, trusted hosts, restricted CORS, security headers, HSTS, and workload identity integration.
